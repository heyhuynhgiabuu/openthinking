# OpenThinking Skills

This is the canonical `skills.sh` install surface for OpenThinking.

These skills are intentionally narrow. Each one should solve one decision problem and produce a reusable artifact.

## Available skills

- `idea-scorecard` — should I pursue this idea now?
- `icp-pain-map` — who is the first real customer and what pain matters?
- `wedge-positioning` — what narrow promise should the product make?
- `mvp-scope-cutter` — what is the smallest real version worth building?
- `pricing-motion-selector` — what pricing motion fits this product shape?
- `gtm-channel-picker` — what single distribution channel should I start with?
- `weekly-review-and-kill-check` — should I continue, revise, or kill this project?

## Install examples

```bash
npx skills add <owner>/openthinking --list
npx skills add <owner>/openthinking --skill idea-scorecard
```
