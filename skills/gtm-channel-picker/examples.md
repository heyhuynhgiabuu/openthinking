# GTM Channel Picker Examples

## Example invocation

> Run `gtm-channel-picker` for a new solo-builder SaaS aimed at developers.
>
> ICP: solo builders who repeatedly start SaaS ideas without validating them properly.
> Wedge: a brutal decision system for solo builders.
> Product type: installable AI skill library with optional hosted workspace later.
> Founder strengths: writing, product thinking, developer audience understanding.
> Available assets: GitHub repo, docs, skill examples, willingness to write sharp content.

## Example output

### Primary channel
**GitHub + developer/founder content that points directly to installable skills**

### Why this channel fits
- the product is naturally packaged as installable skills
- the target audience already discovers tools through GitHub, docs, and technical content
- the founder can create sharp written breakdowns that demonstrate judgment quality

### Why other common channels are weaker right now
- **paid ads:** too early, weak economics, weak signal
- **broad SEO first:** slow and too diffuse before the skill set is proven
- **many social channels at once:** spreads attention too thin
- **cold outbound:** awkward fit for a lightweight solo-builder tool

### 30-day GTM plan
- publish the repo publicly
- ship 3 polished skills with examples
- write 3 short posts showing brutal idea cuts and scope decisions
- share worked examples in builder/dev communities
- collect feedback from real installs and repeated use

### Metrics to track
- repo visits to install conversion
- number of skill installs
- most viewed skill docs
- repeat usage or follow-up skill usage
- inbound feedback quality

## Why this is a good example

It matches the distribution strategy to the actual product shape instead of recommending every channel that might work in theory.
