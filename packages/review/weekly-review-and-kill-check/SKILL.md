# Weekly Review and Kill Check

## Purpose

Use this skill to stop solo builders from drifting for months without real evidence.

## When to use

Use weekly once a project is active.

## Required inputs

- weekly progress
- user feedback
- usage or activation signals
- open questions

## Output contract

Return these sections:

1. `Decision`
   - continue
   - revise
   - kill
2. `Biggest learned truth`
3. `Next week priority`
4. `What to stop doing`
5. `Drift warnings`

## Rules

- be blunt
- do not reward motion without evidence
- distinguish activity from progress
- call out when a project is being protected emotionally instead of rationally

## Stop rules

Stop once there is a clear continue / revise / kill recommendation.
