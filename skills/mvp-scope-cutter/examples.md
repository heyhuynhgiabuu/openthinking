# MVP Scope Cutter Examples

## Example invocation

> Use `mvp-scope-cutter` on this startup idea and cut it into a 2-week MVP.
>
> Wedge statement: a brutal decision system for solo builders who keep starting SaaS ideas without narrowing them enough to validate properly.
> Desired features: idea scoring, ICP analysis, wedge positioning, MVP scoping, pricing advice, GTM planning, weekly reviews, saved history, community gallery, AI chat, integrations.
> Time target: 2 weeks.
> Constraints: solo builder, 10 hours/week, no backend-heavy platform build.

## Example output

### Must-have flow
1. User pastes an idea.
2. User runs `idea-scorecard`.
3. User gets a blunt recommendation plus next step.
4. User runs one follow-up narrowing skill.
5. User leaves with a saved decision artifact.

### Must-have features
- one clean landing page or simple UI entry
- one or two runnable core skills
- structured output format
- copy/export result
- clear next-skill recommendation

### Defer list
- community gallery
- integrations
- full project history UI
- multi-skill dashboard
- generic AI chat surface
- account system beyond the minimum if avoidable

### Non-goals
- founder operating system
- startup CRM
- note-taking tool
- marketplace of prompts
- broad platform for all startup workflows

### 2-week build cut
- week 1: publish `idea-scorecard` and `icp-pain-map` as usable skills with polished examples
- week 2: add a minimal wrapper page or docs flow that shows how to use them in sequence

### Recommended next skill
`pricing-motion-selector`

## Why this is a good example

It cuts hard, preserves one complete flow, and rejects fake-platform creep instead of trying to keep every impressive-sounding feature.
