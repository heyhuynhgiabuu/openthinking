# Wedge Positioning

## Purpose

Use this skill to choose one narrow market entry point and define a clear promise.

## When to use

Use after you have a rough idea and a likely ICP.

## Required inputs

- idea scorecard or equivalent summary
- ICP pain map
- competitor context if available

## Output contract

Return these sections:

1. `Wedge statement`
2. `Promise statement`
3. `Three use cases max`
4. `Anti-positioning`
5. `Why this wedge is better than broader positioning`
6. `Recommended next skill`

## Rules

- pick one wedge
- reject broad category language
- avoid platform wording
- keep the promise clear enough for a homepage headline

## Stop rules

Stop when the product can be explained clearly in one narrow sentence.
